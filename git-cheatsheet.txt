# Консольные команды
`mkdir` - создать папку
`cd` - перейти в созданную папку

# Git-команды

`git add .` - добавить изменения в репозиторий
`git commit -m ""` - создать новый коммит
`git push` - соединить изменения локальные и на GitHub
`git switch` - для пекреключения между ветками
`git switch -c` - создать новую ветку и переключиться на неё
`git branch` - показывает все ветки проекта
`git branch -d` - удалить ветку
`git log` - показывает все коммиты (`--oneline` - выводит короткий лог)
`git fetch --prune` - информация об удалённых ветках

# C-sharp команды
